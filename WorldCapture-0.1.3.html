WorldCapture 0.1.3

  • 不再叠出多个主窗口：开着顶部工具条时，每截一张图都会多开一个一模一样的主界面——现在始终只有一个，截图直接进这个窗口；关掉后再截，也是唤回原来那个。
  • 主界面头部：默认窗口宽度下标题不再被挤成一字一行、右侧按钮不再被裁掉；放不下时按钮自动收成图标（悬停有提示）。
  • Safari 扩展的版本号与 App 保持一致。

English: capturing from the top dock no longer opens an extra main window every time; the header no longer collapses at the default window width (actions fall back to icons when space is tight); the Safari extension now carries the same version as the app.
